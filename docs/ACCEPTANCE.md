# 手工验收清单

以下是待执行清单，不是本次已通过的测试报告。真实 API 操作可能产生费用；本次未执行。

## 1. 本机与画风卡

1. 首次打开，检查 25 张预置卡及图片；预置只能复制，个人卡支持编辑、复制、搜索、删除、导入导出。
2. 填好基础、补充、角色正负面、Seed、参考图。选另一张画风卡：仅画风变化；撤销后恢复原文。
3. 编辑画风卡，生成按钮位于上传头像旁。Token 或测试词为空时仍能点击，弹出填写提示并打开设置定位相应字段，返回后未保存名称/画风/头像仍在。设置统一主体后生成。检查请求顺序为画风→测试内容，512×512、单张、随机 Seed、默认负面，无草稿主体或引导。
4. 头像生成中编辑或删除卡片、取消请求：旧头像保留，不恢复已删除卡片。工作室草稿、主输出不被头像任务替换。
5. 画风库与工作室选择器分别切换全部/V4.5/V5；BOTH 在两种模型中可见，个人卡不限定模型。结合来源、搜索筛选仍正确，切换筛选不改生图模型。
6. 原预置有独立负面词时显示标识，不自动填入；复制为个人卡不带独立负面词。负权重 Tag 不误报为独立负面字段。
7. 上传/生成新头像后取消编辑，旧卡不变；保存后一次更新头像和文本。生成期间关闭、跨页切换或另一标签页删除/修改原卡，完成结果不能覆盖新状态；写入失败保留旧卡，编辑框保留可重试结果。

## 2. 提示词、Tag、法典

1. 中英文、单字、多词、下划线检索，确认全量结果增量显示；Danbooru 排在词典之前。
2. 在中间位置、括号权重、数值权重、source#/target# 内选择候选；仅替换光标前片段，保留后续原文。
3. 全屏编辑取消不写回、确认只修改对应分段；复制粘贴包含字面分段标记、反斜杠、空段与换行时不损坏。
4. 切换 V4.5/V5，比对实际发送文本与 Token 计数。超角色上限明确报错，不截断。
5. 检索法典，查看完整原文。断开资源访问后显示加载错误，恢复后可重试。
6. 设置 → 画风测试提示词：中英文输入均出现预测；在权重和中间光标位置选词，保留后续内容。全屏编辑取消/确认符合工作室规则，生成头像缺词跳转仍定位该输入。
7. 打开翻译，检查中文位于对应原文下方，固定字距靠左，短译文尾部与跨行剩余空白用细横线填充；长译文按行接续，最后一段超宽省略。拖动改变输入高度、滚动、换行、浏览器缩放、中文输入法及全屏编辑时注释跟随，不进入复制文本，不遮挡选择。手机软键盘和长 Tag 不撑宽界面。

## 3. LLM 设计（需测试授权）

1. 配置两个兼容 API 模型，检查模型列表、自定义参数、输出上限、思考参数和关联视觉模型。
2. 新设计描述场景，检查规划→检索→设计→校验/修复→候选。首次请求不得偷偷读入当前工作室正面；开启附加选项后明确携带快照。
3. 修改上一轮，仅围绕前一候选修改；旧轮编辑生成新分支。失败重试与最后一轮重新生成保留预期配置。
4. 图文输入分别走原生多模态和关联视觉模型。截断、过滤、空回复、断网显示失败，不应用不完整候选。
5. 候选应用保留画风；未经点击应用，工作室不变。
6. 比对 APP 与网页的首轮、修改轮、视觉模型、反推请求：相同输入下，系统提示词、全局要求、场景历史角色、法典→Tag 顺序一致；修改轮只沿用首轮证据，附加工作室快照后不再带入旧研究结果。法典随机顺序允许不同。
7. 检查规划别名、围栏 JSON、多对象、finish/空查询、重复词/已有角色词、资源失败、8 秒超时；不把失败显示为完整检索成功。最终解析失败仅修复一次，取消/拒绝停止，不应用未完成候选。

### 模型 ID 检索选择

1. 设置 → 模型配置，填写 HTTPS Base URL 与 Key；点击模型 ID 旁的「检索选择」。从当前地址的 `/models` 获取列表，不能切换到其他服务。
2. 输入空格分隔的多个关键词，确认全部词都匹配；切换系列与 A–Z/Z–A 排序。当前模型在匹配结果中置顶；清除筛选恢复完整列表。
3. 选中一项后关闭窗口，模型 ID 更新。只在显示名称为空时填入名称，思考、输出限制、多模态等配置不变；手动输入仍可用。
4. 当前 ID 不在列表时显示保留提示。刷新失败仍可选择旧列表；首次失败有重试与手填入口；空/不兼容响应不能成为成功空列表。
5. 获取中关闭弹窗、离开设置或删除配置，请求取消且不能自动重开。修改地址/Key 后，旧缓存失效、旧响应不得写入新配置。重新打开成功获取过的列表不重复请求，刷新按钮才重新获取。
6. 检查 401/403、404/405、429、30 秒超时、跨域失败、重复点击刷新。不得自动重试或把 Key 放入网址、错误信息或持久列表。

### 美术与布局

1. 浅色/暗色切换：对照 APP 青绿色主色、表面层次、细边框、圆角与文字层级，确认按钮文字及选中态可读。
2. 检查 APP 原版品牌图标，导航、占位图、AI 设计和图片空状态均为 Lucide 图标；不出现字体符号替代图标。
3. 桌面双栏、平板收窄侧栏、手机单栏保持原布局；模型 ID 长文本及筛选按钮不撑宽弹窗。检查键盘导航、Escape 关闭、手机触摸按钮与软键盘。

## 4. 生图与失败边界（需测试授权）

### 生成设置与角色位置（无需发送生图请求）

1. 依次选择小图/标准/大图/壁纸，再切换竖图/方图/横图；与 APP 尺寸一致，壁纸不出现方图，切换到壁纸时方图转竖图。数量直接点选 1–4。
2. 点比例旁编辑按钮，修改宽高、交换宽高，检查最终像素和比例预览；例如 1000×700 应预览 1024×704。空值、非整数、越界及面积超限禁用确认。取消/关闭不改变草稿，确认后可一次撤销；同预置尺寸的自定义值仍显示自定义。
3. V4.5/V5 来回切换，分别保留该模型尺寸与参数。旧草稿/历史无 sizeChoice 也能识别预置；自定义、历史复现、备份恢复不因新的界面选择状态改变请求宽高。
4. 高级设置摘要正确；展开滑块调 Steps、CFG Scale、CFG Rescale，采样器显示名称；随机 Seed 关闭后显示数值及随数量变化的上限。连续模式入口仍可用。
5. 添加多个角色 → 编辑位置 → 自定义 → 选角色 → 点按/拖动编号画布；数字对应角色顺序，百分比和生效位置联动。V4.5 吸附 10/30/50/70/90%，V5 支持 0–100%。键盘方向键与百分比输入均可替代拖动。
6. 重置均匀排列，确认、撤销；切回 AI 自动再打开自定义，已保存位置仍在。取消/关闭不写入；角色删除/顺序/模型/尺寸或图像引导在编辑期间改变时拒绝旧编辑器提交。
7. 聚焦重绘：尺寸编辑器预览最终原图画布；位置画布使用聚焦区域的请求比例，提示不是整张原图。缺基图或非法聚焦区域时不能确认自定义位置。
8. 手机、平板、桌面检查按钮排列、长角色列表、极端比例、缩放、软键盘；对话框内容可滚动，确认/取消保持可见，拖动画布不滚动页面。

### 实际生成

1. 单张、四张、固定 Seed、随机 Seed、连续模式。生成时编辑草稿，当前请求保持启动快照；下一次才使用新值。
2. 同时双击、另一标签页点击，只有一个生图任务；刷新/断网/关闭后不自动重发。
3. 429 遵循重试提示；普通网络失败不自动重发。流分片任意边界可解析；不完整批次不写历史，之前完整批次保留。
4. 模拟存储不足：旧数据保留，已取得整批图片仍可下载。
5. 账户查询、免费额度与费用估算对照服务实际结果。
6. 首页按钮旁显示 Anlas、V5 百分比及估算张数；首次填写 Token、每 30 秒、返回前台、联网和每批完成后更新。更换 Token/地址不能显示旧账号响应；失败明确标为旧余额，缺少额度字段显示未知。手机宽度下积分、额度、刷新与生成按钮均可见。

## 5. 图像引导与工具（API 步骤需授权）

1. 图生图、焦点八手柄、上下文边界、空/非空蒙版、画笔橡皮、双指缩放、撤销重做。
2. Precise 三种类型、Vibe 多参考与强度归一化；改信息量后重新编码；V5 暂停参考，切回 V4.5 保留。
3. PNG 元数据选择导入，ChatBar Studio 原图恢复分段，独立画风只在选中时替换。图片反推需显式应用。
4. 马赛克、90°旋转、去元数据保留像素和透明度预期；撤销恢复。
5. 静态/GIF 伪装、v1/v2 还原检查真实帧、循环次数和帧延迟；第三方 APNG 不做有损静态编辑。
6. Enhance 比例、强度、Noise 与源图参数；Upscale 输出尺寸、费用；前后对比、下载以及刷新后的工具结果。

## 6. 历史、备份、平台

- 本机 Key：填写 NovelAI/LLM Key 后刷新、关闭重开，自动读取且无口令界面；清空字段或清除本机 Key 后刷新仍为空。写入失败显示错误，不声称保存成功。备份无 `credentials`/`vault` 状态，损坏/非法备份不能注入凭据。旧版密文只提示重填，不静默丢弃。以上检查待执行，不调用付费接口。

1. 按画风/基础/内容/日期多层折叠，搜索及进入/返回范围正确；批量导出顺序正确。
2. 完整复现、随机 Seed、仅应用 Seed、转四种参考图；删除历史不损坏当前参考图和画风卡。
   图片预览→删除这张图片→取消时保留，确认后只移除该图；管理历史→选中单图/整组→检查数量→全选当前结果/清空选择→确认删除。搜索或日期筛选后的删除不影响隐藏项；刷新后删除结果保持。工作室输出预览不出现历史删除按钮。
3. 导出 ZIP，另一浏览器导入：卡片、头像、草稿、历史、对话、工具结果、设置可恢复，Key 不出现。损坏文件/引用/版本必须在替换前被拒绝。
4. 桌面与手机完整跑一遍工作室→设计→应用→生成→历史→工具→备份；检查软键盘、模态框、触摸画布、下载与分享。
5. 离线打开已缓存页面，编辑、查询已缓存词库、查看历史；生成明确失败而非伪装成功。
6. 上线域名再做连接诊断，不能沿用 localhost 结果。
7. 新构建后检查侧栏「检查更新」与版本时间；提示新版准备完成后点击「刷新更新」，旧 Key、草稿和历史保留。停止预览服务时应显示连接失败/缓存提示，不能显示「已是最新界面」；服务恢复后可重试。普通刷新不保证替换正在激活的 PWA 版本，不要求清空网站数据。

### 更新不打断当前页面（待手工验收）

1. 打开 AI 设计，输入未提交文字并滚动；部署新版，等待至少两次一分钟轮询，再切换前后台、断网重连。仅显示更新提示，无整页闪烁、无 boot 页面，输入和当前页面保留。
2. 当前版本相同但存在 waiting SW 时，后台检查不得发送 SKIP_WAITING。首次安装不弹新版提示；其他标签页激活更新、平台 SW 接管时，本页不刷新。
3. 保存编辑后主动点击刷新更新：草稿与设置落盘，目标 SW 接管后只导航一次；更新等待期间不能重复点击或提交新任务。非 SW 浏览器也可主动更新。
4. 生图/AI 设计进行中，或存在未保存输出时，刷新更新禁用；任务结束仍须用户点击，不自动排队刷新。
5. 存储失败、SW 安装失败/被替换、12 秒激活超时、其他 scriptURL 接管：显示错误并保留页面，迟到的事件不能刷新。恢复后可重新点击。
6. 回归离线启动、Tag 查询、设置 ZIP 替换、错误页主动重试。主动更新依然是文档刷新；本轮不声称保留未提交的局部编辑或实现代码热替换。
